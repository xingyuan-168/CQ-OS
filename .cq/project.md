# CQ OS 项目背景

- 目标：成为 DSH 第五种用户 Agent 模式，形成 AI 软件工程组织。
- 当前版本：0.1.0
- 源码：工作区 Git 仓库的 `preset/`
- 部署：DSH 用户预设目录中的 `cq-os`，仅为部署产物
- 范围：DSH 原生预设、九个专业子 Agent、治理技能、CQ Memory、真实人机确认
- 后置：动态模型路由、硬策略 RBAC、第三方插件标准、结构化 Memory
