# ADR-0021 草案：Git Markdown 权威源 + 可重建派生索引

## 状态

Draft，等待 V2.1 PoC。

## 决策建议

保留 `.cq/` Markdown 作为项目记忆唯一权威源，采用零依赖 `index.json` 派生索引和 DSH 原生 grep/glob 全文检索。索引可删除并从 Markdown 幂等重建。只有在过滤/全文性能验证不足时，才引入 `better-sqlite3` 或复用 DSH SQLite/FTS5 方案。

## 放弃方案

Mem0、Letta、Zep 和 LanceDB 需要服务、向量、图谱、embedding 或完整 Agent runtime，与 Git-backed 工程知识和 Windows 低依赖目标不匹配。`node:sqlite` 可零依赖但当前 FTS5 能力不足，作为备选记录。

## 迁移

V1 文件不删除、不覆盖；缺字段标记 legacy；重复和缺 commit 只报告；索引损坏可从 Markdown 恢复。
