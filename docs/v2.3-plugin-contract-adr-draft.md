# ADR-0023 草案：薄 CQ Plugin 契约与独立维护预设

## 状态

Draft，等待 plugin row/isolate/host-plane PoC。

## 决策建议

复用 npm package.json、SemVer、exports、DSH plugin rows 和 AgentPresets generation。只增加薄 `cq-plugin.yml`，声明兼容性、依赖、贡献 rows/skills/templates、权限、迁移、生命周期和安全自评估。清单权限不替代运行时 guard/approval/sandbox。

日常 `cq-os` 永不挂载 tool-cordis；维护能力使用独立 `cq-os-maint` 用户预设，由人类显式开启，Git review 后通过 standingKeyFor 部署。

## 未决 PoC

需要验证消费型 row、isolate 服务行、松散服务行和 host-plane row 的真实 standingKeyFor 行为；若 runtime 不拒绝违规组合，增加最小契约校验器。
