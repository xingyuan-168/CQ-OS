# ADR-0023 草案：薄 CQ Plugin 契约与独立维护预设

## 状态

Draft。离线 manifest 校验器、创作期合并器与 fixture 已通过；仍等待真实 plugin row/isolate/host-plane 挂载 PoC。

## 决策建议

复用 npm package.json、SemVer、exports、DSH plugin rows 和 AgentPresets generation。只增加薄 `cq-plugin.yml`，声明兼容性、依赖、贡献 rows/skills/templates、权限、迁移、生命周期和安全自评估。清单权限不替代运行时 guard/approval/sandbox。

组合采用候选 B（创作期合并）：`tools/cq-plugin-compose.mjs` 把插件声明的 rows 片段并入目标 preset 文本，校验行 id 冲突、拒绝 host-plane manifest，并在 `preset/` 源码内生成可 Git review 的产物。它不部署、不触碰 DSH 用户预设目录。

日常 `cq-os` 永不挂载 tool-cordis；维护能力使用独立 `cq-os-maint` 用户预设，由人类显式开启，Git review 后通过 standingKeyFor 部署。

## 未决 PoC

需要验证消费型 row、isolate 服务行、松散服务行和 host-plane row 的真实 standingKeyFor 行为；若 runtime 不拒绝违规组合，扩展现有最小契约校验器。当前 `tools/cq-plugin-validate.mjs` 已 fail-closed 拒绝非法 id、host-plane、缺失 capabilities/lifecycle、空 row 和不满足的 cqOS/DSH 简单比较区间；它只验证声明，不能替代运行时权限执行。
