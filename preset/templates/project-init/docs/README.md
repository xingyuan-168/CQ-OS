# Documentation root for a new project.

Add project docs here: user guide, architecture, operations, and API reference.
Use the CQ OS convention: `preset/` and `docs/` are source-controlled; `.cq/` holds
distilled project memory.

Suggested structure:

- `README.md` — quick start
- `ARCHITECTURE.md` — system design and data flow
- `API.md` — public interface reference
- `OPERATIONS.md` — deploy, run, and monitor
